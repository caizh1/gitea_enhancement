# 群组导航实现与验收报告

## 结论

VERDICT: PASS

P0/P1 BLOCKERS: 无。此次结论针对群组导航 Demo 修订，不代表三项企业治理全部生产验收完成。

发布版本：`1.27.3-demo.20260916.2`；程序：`1.27.3+governance.demo.nav7`。数据库结构版本仍为 370。

## 实现范围

- 首页折叠群组树、稳定 ID、完整路径、独立子组入口、每层分页与搜索。
- 群组主页的直接子群组和仓库、后代搜索、活动状态、排序、连续面包屑。
- 原生创建入口携带父级、完整路径预览、私有父组下仓库默认私有。
- 成员直接、继承、共享、继承共享、原生团队来源；组合权限、到期记录、来源管理链接和直接授权编辑。
- REST 导航接口及 OpenAPI，网页会话使用同一查询服务的 Web 适配入口，未放宽 REST 全局认证。
- 清空搜索重新检查当前层和已展开层权限，同时保留合法展开状态。
- 保留原生仓库、README、团队、软件包、看板及动态入口；旧群组详情链接兼容。

## 首次失败与修复

1. 网页树调用要求令牌的 REST 地址，导致会话用户加载失败。改用 Web 会话适配入口，服务层和权限计算共用。
2. 将公开仓库可读误算为成员关系。改为检查真实团队、直接和治理授权；已保留首次失败并通过负向回归。
3. 撤权后的搜索拒绝正确，但清空搜索恢复旧列表。增加清空搜索时的各已展开层复查；保留修复前后截图，并验证恢复权限后重试成功。
4. 前端资源变化时 Makefile 可能沿用旧 Go 程序。构建脚本强制重新编译，并在镜像内核对版本；最终发布程序已核实为 nav7。
5. 旧首页测试样本在迁移后载入，未建立生产迁移已有的命名空间。测试补齐初始化，保留原完整路径断言并通过；未通过削弱断言掩盖产品错误。
