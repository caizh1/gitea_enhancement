## 撤销邀请的真实收件人反馈

第六版邀请2已经过 UI 创建、隔离 SMTP 投递及 Owner 撤销。第七版收件人打开邮件时，页面停留在预览表单。临时仅记录路径的 router 日志证明浏览器已经发出 POST，服务端返回 404；不是 token 未填、请求未发送或授权放行。旧响应为 `text/plain`，本次 IAB 未把其显示成新错误页，不能据此推断全部浏览器行为。

第八版仅将邀请决策中的“未找到／无权”转换为现有原生 HTML 404，保留状态码及邮箱、token、生命周期校验。收件人 `phase1-outsider` 再次打开同一已撤销邮件，真实页面显示 `404 Not Found` 及“不存在或无权查看”，不显示资源、邀请邮箱或 token。对应自动化覆盖 preview 和 accept 两种请求，成员未新增。
