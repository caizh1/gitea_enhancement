完成审查后填写 `VERDICT: PASS` 或 `VERDICT: FAIL`，并保留以下栏目。

### P0/P1 BLOCKERS

待审查。每项记录严重级别、具体位置、触发条件、完整因果链、实际影响、为何阻塞发布、支持证据、反证过程及复测结果。无阻塞项明确写“无”。

### UNVERIFIED RISKS

待填写未执行场景、缺少环境、并发控制缺口及无法确认的风险，不计作已成立阻塞项。

### NON-BLOCKING FINDINGS

待填写 P2/P3 与改进建议，不影响审查 VERDICT。

### 实际验收边界

待填写已执行的实例版本、平台和范围，以及仍需真实环境验收的部分。审查 PASS 不自动表示全矩阵完成。
