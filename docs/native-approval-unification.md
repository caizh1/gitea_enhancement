# 原生分支保护与审批规则统一开发说明

## 交付目标与边界

本次修改位于 Gitea 1.27.3 原生治理开发基线。审批入口合入仓库分支保护；仓库共享规则位于设置中的“拉取请求”，群组与实例规则位于各自原生设置，PR 从原生审批区域查看和管理规则。Manager 不新增审批配置。

完整工作区（含未提交和未跟踪源码）已保留到 `gitea-approval-unification-baseline`。开发工作区 `gitea-approval-unification` 已整合群组任务提供的导航、路径和公共页面修改。隔离开发没有仅从旧 HEAD 起步。

## 页面与操作

分支保护编辑页保留匹配表达式、推送和合并权限，将审批规则、来源、所需人数及仓库级设置放在同一表单。CI、签名、评审阻断、文件与强制推送等原生选项仍可展开配置。规则弹窗只修改草稿；底部保存一次提交全部内容。关闭弹窗、取消和离开不写规则。未保存修改提示离开确认。

单一保护规则专用规则可直接编辑；共享规则进入仓库拉取请求设置管理。上级规则在本页只读，有源设置权限时显示来源链接。隐藏主体由服务端投影并保留，不能通过编辑其他字段清空它们。审批设置明确影响整个仓库，锁定设置在来源修改。

通配保护表达式可能覆盖多条实际分支；上级声明式范围在实际 PR 目标分支解析。配置页可能列出通配范围内的候选上级规则，具体适用情况以 PR 逐规则状态为准。配置页的候选人数不会替代 PR 当前作者、提交者与成员关系下的有效资格判断。

## 权威配置与合并

`ApprovalRule` 是唯一审批规则来源，新增稳定保护 ID 关联。原生人数和名单是兼容投影，原生写入与统一规则同事务更新。迁移原生规则仍保留原保护优先级、名单和过期批准语义，不能被 PR 自定义覆盖移除。

每条规则独立计票，同一人在同一规则只计一次，可同时满足多个组规则。总人数按身份去重。必需规则不足阻止合并，零人规则可选。候选人由服务端基于有效账号、访问权限、当前成员关系与审批设置计算。

复用原生批准、撤回及评审记录。有效证据绑定差异版本；相同差异 rebase 不无条件清票，差异 A→B→A 不复活旧证据。迁移历史批准只在可证明的兼容条件下参与，不伪造新的证据。规则快照与项目覆盖设置沿用现有生命周期；上级和迁移原生强制要求始终取当前有效配置。

网页、API 和自动合并走统一审批状态。原生独立人数检查已移除，其他保护检查保留。最终引用事务校验仍执行源提交、目标与审批状态验证及授权预留。原生审批有要求但缺失对应统一记录时失败关闭，不能悄悄绕过。

真实 Git 验收发现原有命令包装丢弃 Git 隔离对象环境，导致保护合并读取新对象失败。修复 `modules/gitrepo/command.go` 保留调用者环境，未通过跳过原生保护规避问题。

## 原子写入和兼容接口

`SaveBranchApprovals` 在已有治理写入保护下校验版本、权限、主体、范围及锁定，保存保护配置、规则、设置与审计。完整保护保存须仓库管理员；仅管理审批能力只能调用审批保存，不获得推送、CI 或管理员例外修改能力。引用事务入口安装为明确操作，不在数据库事务内隐式写 Hook。

原生 `branch_protections` 返回 `approval_configuration` 对象，包含版本、规则、来源展示、有效设置与能力。创建和编辑可附同名对象，一并提交本地审批变更。批量审批保存为：

`PUT /api/v1/governance/repositories/{id}/approval-configuration`

请求包括 `version`、`protection_id`、`rules` 和可选 `settings`。规则变更元素包括 `rule`、`revision`、`remove`。旧客户端继续使用原审批字段局部更新，省略字段不清除新规则。同一请求的新旧表达不一致会拒绝，相同表达接受。新页面必须提交版本，过期草稿返回冲突。Swagger 已同步生成。

保存后的 PR 刷新失败与保存失败区分：原生 API 通过 `X-Gitea-Protection-Refresh: pending` 提示，网页显示已保存但刷新待处理；最终合并仍读权威配置。网络丢失导致结果未知时应重新读取版本确认，不能盲目重复提交。

旧治理 GET 地址先鉴权再跳转原生页面；旧写接口继续兼容。独立审批编辑模板已经迁入共享模板，原生页面复用同一服务。

## 默认值与支持边界

新仓库默认禁止作者批准、代码差异变化后重新批准；禁止提交者、禁止 PR 覆盖与重新认证默认关闭。已有有效设置保留。重新认证受既有认证能力约束。

本次未扩展 CODEOWNERS、安全扫描与安全策略。源码和隔离包验收不等于目标内网生产验收。容量、持续运行和人工减少 80% 指标尚未完成测量。
